# World ID IDKit Pilot Signoff Evidence

This directory contains the repository-side evidence index for `WORLDID-250`.
Target environments must replace every placeholder in
`docs/WALLET_TARGET_PRODUCTION_SIGNOFF_PACKET.template.json` with approved
artifact IDs from the deployment evidence system.

The index in `pilot-signoff-evidence-index.json` lists the minimum evidence
classes required before `WORLD_ID_ENVIRONMENT=production` can be enabled.
