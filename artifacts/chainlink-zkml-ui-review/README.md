# Chainlink ZKML UI Review

This artifact records the CLZKML-285 cross-surface UX review scope for Chainlink consensus wallet surfaces.

The Playwright spec `wallet_interface/ui/tests/chainlink-consensus-ux.spec.ts` writes route screenshots into this directory during validation and checks keyboard reachability, accessible consensus labels, manual-review fallback visibility, non-overclaiming proof labels, no horizontal overflow, and no private consensus sentinel leakage.
